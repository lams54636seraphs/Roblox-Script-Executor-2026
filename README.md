## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled together with a universal loader called xcutorsLoader, designed for Windows desktop users who want a convenient all-in-one package.

### Is XCutors free to use?

Yes. XCutors and all included executors (Volt, Synapse Z, Potassium, Wave) are completely free to download and use from the official GitHub repository.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit editions). Older versions such as Windows 7 or 8 are not officially supported.

### How do I update the executors?

Open xcutorsLoader and click the 'Check for Updates' button. The loader will automatically detect and download the latest versions of each executor.

### Can I use my own custom Lua scripts?

Absolutely. Every included executor allows you to paste or load custom .lua files directly. You can also browse the built-in script hub for community-shared scripts.

### Which executor should I choose?

It depends on your needs. Volt is lightweight and fast, Synapse Z offers the most features, Potassium balances performance and stability, and Wave focuses on a modern UI. Try each one through the loader to see which you prefer.

### My anticomponent is flagging the files. Is it safe?

Executor tools are commonly flagged as false positives by anticomponent software because they inject code into other processes. Always download XCutors only from this official repository. You may need to add an exception in your anticomponent settings.

### Do I need to run the loader as administrator every time?

Yes. Running xcutorsLoader.exe with administrator privileges is required so the executor can properly attach to the Roblox process and execute scripts.

### The executor is not attaching to Roblox. What should I do?

Make sure Roblox is fully launched and you are in a game before clicking 'Attach'. Also verify you are running the executor as administrator and that your anticomponent is not blocking the process.

### Where can I report bugs or request features?

Please open an Issue on this GitHub repository. Provide as much detail as possible, including your Windows version, the executor you were using, and steps to reproduce the problem.
